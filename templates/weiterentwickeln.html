Deine eigene JR-Maths-Seite.

Du bekommst den vollständigen Quellcode mit allen Inhalten. Die fertige Seite besteht aus HTML, CSS und JavaScript. Python erzeugt die HTML-Seiten aus den Kapiteldateien und wird nur beim Bauen benötigt.

Komplettes Projekt als ZIP

1. In Visual Studio Code öffnen

  1. ZIP herunterladen und vollständig entpacken.
  2. In Visual Studio Code über Datei → Ordner öffnen den Ordner mathepfad wählen. Gemeint ist VS Code; die große Visual-Studio-IDE ist nicht erforderlich.
  3. Für reine Vorschau dist/index.html im Browser öffnen. Navigation und Lösungen funktionieren auch direkt aus dem Ordner.
  4. Für Änderungen an Kapiteln Python 3 installieren und das VS-Code-Terminal im Projektordner öffnen.
# Windows
py build.py
py export.py
py check.py
py -m http.server 8000 --directory dist

# macOS / Linux: python3 statt py

Öffne anschließend http://localhost:8000. Beenden mit Strg+C. Nach einer Inhaltsänderung erneut bauen und den Browser neu laden. In VS Code sind außerdem Aufgaben unter Terminal → Aufgabe ausführen vorbereitet.

3. Ein Kapitel erweitern

Öffne beispielsweise content/Q1.1.json. Ergänze im Array tasks eine Aufgabe. Gib ihr eine neue, dauerhafte Kennung. Bestehende Kennungen und Slugs möglichst nicht ändern, damit Schülerlinks weiter funktionieren.

{
  "id": "Q1.1-09",
  "level": "Mittel",
  "title": "Integral berechnen",
  "question": "Berechne das Integral von 0 bis 2 über 3x².",
  "steps": [
    "Eine Stammfunktion ist F(x)=x³.",
    "F(2)−F(0)=8−0=8."
  ]
}

Für ein neues Kapitel kopierst du eine Kapiteldatei, änderst id, slug, name und den Inhalt. Der stage-Wert ordnet es einer vorhandenen Lernstufe zu. Die Navigation entsteht automatisch. Text wird sicher als Text dargestellt; HTML-Tags gehören nicht in die JSON-Felder. Ein vollständig beschriebenes Beispiel liegt in docs/kapitel-vorlage.json.

4. Mit GitHub Pages öffentlich bereitstellen

Der mitgelieferte Workflow baut die Site bei einem Push auf main. Relative Links funktionieren auch unter einer Projektadresse wie name.github.io/mathepfad/.

  1. Ein neues GitHub-Repository anlegen, zum Beispiel mathepfad. Für GitHub Free ein öffentliches Repository verwenden.
  2. Den entpackten Projektinhalt in dieses Repository übernehmen. Der Quellcode liegt danach in deinem eigenen GitHub-Konto.
  3. Im Repository Settings → Pages → Build and deployment → Source: GitHub Actions einstellen.
  4. Den Code auf den Branch main pushen. Alternativ unter Actions den Workflow „Mathepfad auf GitHub Pages“ manuell starten.
  5. Nach erfolgreichem Workflow zeigt GitHub Pages die Adresse. Diese können Schüler auf Handy, iPad und PC öffnen.
git init -b main
git add .
git commit -m "Mathepfad starten"
git remote add origin DEINE_GITHUB_REPOSITORY_URL
git push -u origin main

Ersetze den Platzhalter durch die URL deines Repositories. Die GitHub-Anmeldung erfolgt über deine lokale Git- oder VS-Code-Anmeldung. Bei späteren Änderungen reichen Bauen/Prüfen, Commit und Push. Der Workflow baut zusätzlich selbst.

5. Anderes Hosting oder eigener Webserver

Nach build.py und export.py kannst du den Inhalt von dist/ auf jeden statischen Webhost hochladen. index.html muss im Webwurzelordner liegen; Unterordner und Dateinamen bleiben erhalten. Der Server muss weder Python noch Node.js ausführen. HTTPS und eine Domain werden beim jeweiligen Anbieter eingerichtet.

Für einen kurzen Test im eigenen WLAN kannst du den lokalen Server nutzen und am Handy die lokale IP-Adresse deines PCs mit Port 8000 öffnen. PC und Handy müssen im gleichen Netz sein und die Firewall den Zugriff erlauben. Das ersetzt kein dauerhaftes Internet-Hosting; der PC müsste dabei eingeschaltet bleiben.

6. Modular weiterbauen

Neue Inhalte benötigen hauptsächlich neue JSON-Dateien. Änderungen am Design gelten über die gemeinsame CSS-Datei für alle Kapitel. Später können Benutzerkonten und eine Datenbank ergänzt werden; Aufgabenkennungen sind bereits stabil. Für den jetzigen Nachschlagebetrieb brauchst du das nicht.

Das heruntergeladene Projekt enthält keine Bindung an das bisherige Sites-Projekt. Die bestehende Sites-Veröffentlichung behält ihre aktuellen Zugriffsrechte. Für Schüler, die jederzeit ohne Anmeldung nachschlagen sollen, nutze die eigene öffentliche Veröffentlichung.
